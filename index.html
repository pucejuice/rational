Notes:
• Rational Method per QUDM: Q = Cy · I · A / 360 (Q in m³/s, I in mm/hr, A in ha)
• C₁₀ = 0.9 · fi + Cperv · (1 − fi) with Cy = Fy · C₁₀ ≤ 0.9
• Frequency factors from QUDM Table 5.05 (Fy relative to 10% AEP)
• 1% AEP 2100: current 1% AEP intensity × 1.20 climate change factor
• IFD intensities interpolated using log-log method between standard durations
• Detention: Modified Puls level-pool routing with triangular inflow hydrograph (tbase = 2 × storm duration)
• Modified Puls: (2Sn+1/Δt + On+1) = (In + In+1) + (2Sn/Δt − On) — iteratively solve for stage, storage & outflow at each time step using the stage-storage-discharge relationship
• Orifice: Q = Cd·A·√(2g·heff), Cd = 0.6, heff from water level to orifice centre
• Overflow: Q = 1.7·L·(h − H)1.5 broad-crested weir at tank height
• Non-worsening: total site outflow (tank discharge + bypass) ≤ existing site peak flow
• Pilgrim & McDermott: tc = 0.76·A0.38 (hrs, A in km²) for storm duration
